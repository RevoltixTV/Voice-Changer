Einrichtung

Für OBS, Discord, Teams, Skype oder WhatsApp wird ein virtuelles Audiokabel wie VB-Cable oder Virtual Audio Cable benötigt. Voice Carnage sendet an „CABLE Input“, die anderen Programme wählen „CABLE Output“ als Mikrofon.

OBS Studio: Audio-Eingabe-Aufnahme hinzufügen → Gerät „CABLE Output“ → Testen.

Discord: Einstellungen → Sprache & Video → Eingabegerät „CABLE Output“.

Microsoft Teams: Einstellungen → Geräte → Mikrofon „CABLE Output“.

Skype: Einstellungen → Audio & Video → Mikrofon „CABLE Output“.

WhatsApp Desktop: Einstellungen → Audio → Mikrofon „CABLE Output“.

Taste belegen

Voice Carnage installieren

1. Virtuelles Kabel: Damit OBS, Discord & Co. dich hören, installiere VB-Cable und starte den PC neu.

VB-Cable herunterladen

2. Windows-Programm: ZIP entpacken, im Ordner npm install und dann npm run dist ausführen. Danach liegt die Datei „Voice Carnage.exe“ im Ordner „dist“.

3. Alternative: Läuft die Seite über https, kannst du sie in Chrome oder Edge über das Installieren-Symbol in der Adressleiste als App installieren.
