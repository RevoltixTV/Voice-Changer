VOICE CARNAGE - als App starten
1. Node.js installieren (nodejs.org).
2. VB-Cable installieren (vb-audio.com/Cable) und den PC neu starten.
3. In diesem Ordner im Terminal:  npm install   dann   npm start
   Als .exe bauen:  npm run dist   (Ergebnis im Ordner "dist")
4. In Voice Carnage: Zahnrad > Ausgabe = "CABLE Input", Mikrofon aktivieren.
5. In OBS / Discord / Teams / Skype / WhatsApp als Mikrofon "CABLE Output" waehlen.
OBS-Tasten: In OBS Werkzeuge > WebSocket-Servereinstellungen > Server aktivieren, dann in Voice Carnage unter Einstellungen verbinden.
